内置工具

hpm 与 hncc 完整用法

HNeoC-OS 自带两个"在系统里干活"的工具：hpm 装软件，hncc 编译 C。这一页是它们的完整用法。

hpm 包管理器

HNeoC 没有网络，"软件源"就是磁盘上的 /var/hpm/repo 目录。用法照着 apt 来：

hneoc$root~/ hpm avail                  # 仓库里能装的包（i = 已装）
hneoc$root~/ hpm install examples       # 安装，自动先装依赖
hneoc$root~/ hpm list                   # 已装的包
hneoc$root~/ hpm info <包名>            # 详细信息（真的去读一遍包头做对照）
hneoc$root~/ hpm files <包名>           # 这个包装了哪些文件
hneoc$root~/ hpm verify                 # 检查已装文件是不是都还在
hneoc$root~/ hpm remove <包名>          # 卸载：删掉它装出来的每个文件
hneoc$root~/ hpm update                 # 重扫仓库目录、重建索引
hneoc$root~/ hpm search <词>            # 按包名和说明搜
子命令作用
hpm用法 + 仓库/已装概况 + 当前身份
hpm list已装的包
hpm avail仓库里能装的包（i 表示已装）
hpm search <词>按包名和说明搜
hpm info <包名>详细信息，并且真的去读一遍包头做对照
hpm install <包名>...安装，自动先装依赖（examples 依赖 hello + tools）
hpm remove <包名>卸载：删掉它装出来的每个文件，并更新数据库
hpm files <包名>这个包装了哪些文件
hpm verify检查已装文件是不是都还在
hpm update重扫仓库目录、重建索引（相当于 apt update，只是源在本地）

镜像内置四个包：docs（hpm 与 HNeoFS 磁盘布局的文本说明）、examples（hncc 示例源码）、hello（hpm 演示程序）、tools（calc 整数计算器）。

hneoc$root~/ hpm install examples
hneoc$root~/ hi                        # 装完就能跑

💡 安装要靠包头里的权限位恢复执行位——新建的文件默认 0644 没有执行位，非 root 用户就跑不起来。

hncc：在系统里编译 C

hncc 是一个跑在 HNeoC 上的 C 编译器，自己生成 x86 机器码，不经过任何汇编器或链接器：

hneoc$root~/share/hncc hncc hello.c
compiled hello.c
  code   : 5874 bytes
  data   : 113 bytes
  bss    : 4 bytes
  output : hello.lxe

hneoc$root~/share/hncc ./hello.lxe
hello from a program that hncc compiled on HNeoC

用法：share/hncc hncc <源文件> 产出同目录的 .lxe，再用 ./<程序> 运行。

支持的 C 子集

  • 类型：int char void、指针、数组、struct、enum、typedef；uint8_t/uint16_t/uint32_t/int32_t/size_t/bool 内建（不需要 #include）
  • 语句：声明（可带初值）、if/else、while、do-while、for、switch/case/default、return、break、continue
  • 运算：+ - * / %、比较、&& ||（短路）、! ~ & | ^ << >>、++ --、赋值与复合赋值、? :、[]、()、& *、sizeof、强制类型转换
  • 结构体：定义、前向声明、a.f、p->f（可串链）、结构体数组、sizeof(struct T)、typedef
  • 初始化：int a[4] = {1,2,3,4};、char s[] = "abc";、长度自动推断
  • 变参：printf(fmt, ...)；自己写带 ... 的函数也行
  • 其它：函数（递归、前置声明）、全局变量、#define 常量

自举试验

build.ps1 会把 user/hncc.c 拷进镜像的 /share/hncc/hncc.c，可以直接让 hncc 编译它自己：

hneoc$root~/share/hncc hncc hncc.c

这条路拿一份约 4900 行的真实程序去撞编译器的每一条限制，撞出来的每个缺口都补上了对应的诊断和回归检查。

已知限制

以下都是明确报错，不会默默生成坏代码：

  • 不支持浮点、long long（当 int 处理）、真正的预处理器、多文件编译
  • 结构体只能通过指针传递和返回，不能按值传、不能整体赋值
  • 结构体不能包含自己（可以包含指向自己的指针，链表能写）
  • 调用实参最多 16 个
  • 局部变量不能和 typedef 名重名
  • 初始化列表不支持嵌套（如 int m[2][2] = {{1,2},{3,4}}）

/share/hncc/ 下有八个例子：hello.c、fib.c（递归 + 数组 + 指针）、t1.c~t7.c（数字/结构体/初始化/printf/enum/typedef 七组数字诊断）。
