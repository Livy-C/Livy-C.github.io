使用指南

Shell、命令、vi 与权限

这一页覆盖日常使用：Shell 怎么用、有哪些命令、怎么编辑文件、权限是怎么回事。

Shell 快速上手

几个核心概念：

  • 磁盘优先：敲任意命令时，Shell 先找磁盘上有没有 /bin/<命令名>.lxe，找到就交给 ring 3 程序执行；找不到才回退到内核内置命令。
  • 行编辑：退格、方向键、Home / End / Delete、Ctrl+U（清行）、Ctrl+L（清屏），↑/↓ 翻 20 条历史命令。
  • 回看滚过的输出：鼠标滚轮一次 3 行，PageUp/PageDown 一屏，Home 到最旧，End 回实时画面；按其他任意键也会回到实时画面。
  • 后台任务：行尾加 & 即可后台运行，如 bg &。
  • Ctrl+C：杀死当前前台进程；在提示符下按 Ctrl+C 会杀掉 Shell 本身，内核随即重新拉起一个——效果等于重新登录。

💡 改了内核内置命令却看不到效果？因为 Shell 是磁盘优先的——ls 敲下去先跑 /bin/ls.lxe。要验证内置命令的改动，先 rm /bin/ls.lxe 去掉抢跑的程序。

文件操作

hneoc$root~/ ls /bin          # 看 /bin 里有什么
hneoc$root~/ cat readme.txt   # 读文件
hneoc$root~/ cd /home         # 切目录
hneoc$root~/home mkdir d1     # 建目录
hneoc$root~/home note         # 往 notes.txt 追加一行

数据真的落盘：note 写的行在重启（用 -NoBuild，不重新打包镜像）之后依然在。

vi 编辑器

vi 是从零写的全屏编辑器（约 1700 行），支持计数前缀（3j、2dd）、多级撤销（8 级）、搜索（/ ? n N）。

类别按键
移动h j k l、方向键、0 $、w b、gg G、PageUp/PageDown
删除dd dw d$ d0、dj dk、D、X
复制粘贴yy yw y$、p P
修改cc cw C S（改完直接进插入模式）
其它r 替换字符、J 续行、u 撤销
进入插入i a A I、o O
命令:w :w <文件> :q :q! :wq :x :e <文件>、:<行号>、ZZ

命令行可以直接带文件：vi readme.txt。

账户与权限

账户表在 /etc/passwd，一行一个账户，字段用冒号分隔：

name:password_hash:uid:home:admin
root:7c9d79a9:0:/:1
livy:7c9a16c9:1000:/home:1
guest:0f88c14d:1001:/home:0

admin = 1 表示管理员：能加账户、能往别的用户的地盘写。uid 0 永远是 root。

权限位借用 Unix 的三组三位写法（中间"组"三位不参与判断，因为没有用户组）：

权限数值含义
07550x1ED属主可读写执行，其他人可读可执行（目录、.lxe）
06440x1A4属主可读写，其他人只读（普通文件）
07770x1FF谁都可读写（/home）

判断规则：uid == 0 或 admin 一律放行；属主看高三位，其他人看低三位。根目录没有自己的目录项，"往 / 里写"一律要求管理员。

guest 用户的真实边界（都在虚拟机里核对过）：

操作结果
在 /home 里 mkdir mine、写文件、删除✅ 成功
mkdir /nope❌ permission denied
rm /motd.txt❌ cannot remove（/ 不归他）
useradd hacker❌ only an administrator can add accounts
