HNeoC-OS 是什么、如何快速跑起来

HNeoC-OS 是一个从零写起的类 Unix 小型操作系统（x86 32 位），用来学习操作系统原理。当前版本 0.3.0——它已经不是一个玩具 Demo：物理内存管理、分页、ATA 磁盘驱动、自研文件系统、ring 3 用户态、系统调用、抢占式多任务，一应俱全。Shell 本身也是一个 ring 3 用户程序，磁盘上的每条命令都是独立可执行文件，靠 fork + exec + wait 跑起来，和真实 Unix 一样。

特性

  • 从引导扇区到用户态：512 字节 boot → 保护模式 → 内核 → ring 3，全部手写
  • HNeoFS：自研文件系统，目录树 + 连续存放，可写、可删除，数据真落盘
  • 30 个系统调用：fork / exec / wait、文件 I/O、sbrk、chmod、listdir……
  • 抢占式多任务：PIT 100Hz 调度，16 个进程槽，僵尸回收与孤儿过继
  • 多用户与权限：root / livy / guest 三账户，Unix 三位权限位
  • 用户态 Shell：/bin/sh.lxe 跑在 ring 3，提示符、行编辑、历史、PATH 查找全在用户态
  • vi 编辑器：约 1700 行的全屏模态编辑器，支持计数前缀与多级撤销
  • hpm 包管理器 与 hncc 编译器：在系统里装包、编译 C，还能让 hncc 编译它自己

快速开始

环境要求

组件位置说明
NASM.\tools\nasm.exe汇编引导扇区和中断存根，随仓库附带
MinGW-w64 i686D:\mingw32\bin必须是 32 位版本
VirtualBoxD:\VB可选，用于生成 VDI 和自动化测试
PowerShell 5.1+—构建与运行脚本均为 PowerShell

⚠️ MinGW 必须是 i686（32 位）。用 gcc -dumpmachine 检查，输出 i686-w64-mingw32 才对。

构建与运行

.\build.ps1 -VmName "HNeoC"   # 构建，并自动把新磁盘挂到虚拟机上
.\run.ps1                      # 构建 + 无头启动 + 打印屏幕内容
.\run.ps1 -Type "ls"           # 启动后自动敲一条命令
.\run.ps1 -Stop                # 关机

构建完成后，打开 VirtualBox 图形界面启动 HNeoC 虚拟机即可交互。

⚠️ build.ps1 每次都会重新生成 VDI，会清掉磁盘上运行时的改动。只想重启验证数据持久化（比如 note 命令写的 notes.txt），用 .\run.ps1 -NoBuild。

登录系统

镜像预置三个账户（用户名 / 密码相同）：

账户密码身份
rootroot管理员（uid 0）
livylivy管理员（uid 1000）
guestguest普通用户（uid 1001）

提示符格式为 hneoc$用户名~/工作目录，$ 和 ~ 是字面字符。随时可以用 login 命令切换身份。
