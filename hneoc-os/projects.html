其他项目

其他仓库的使用说明

除了 HNeoC-OS，还有其他几个项目。这一页是它们的简要使用说明。

其他项目

The Blockrooms

Minecraft Blockrooms 模组（Java，NeoForge 平台），fork 自 HYP-HLP/the-blockrooms。把阈限空间（liminal spaces）搬进方块世界。

使用：作为 NeoForge 模组安装——将构建产物放入 .minecraft/mods/，配合对应版本的 NeoForge 加载器运行。

BackroomsDelight

Minecraft Fabric 模组，把 Backrooms 作为无限、程序化生成的空间加入游戏。

环境要求：Minecraft 1.20.1 · Fabric Loader 0.19.5+ · Fabric API 0.92.12+1.20.1。

使用：构建产物放入 .minecraft/mods/，需同时安装 Fabric API。

EndRingReborn

Minecraft Fabric 模组（客户端与服务端均可），让被移除的末地环（end ring）回归。

使用：依赖 Fabric Loader 与 Fabric API，产物放入 .minecraft/mods/。

OneHourSurvival

一小时生存玩法插件（"A simple one-hour survival plugin"）。

💡 仓库目前处于早期阶段（默认分支仅有 LICENSE），暂无构建产物与安装说明，后续更新后补充。

kun-liminal-theme

为 The Kunrooms Wikidot 站点编写的 liminal 风格主题，仓库为五个 CSS 文件（kun-liminal.css、creeper-face.css、creeper-face-blrver.css、level-class-modify.css、meme-doc-comp.css）。

使用：在 Wikidot 站点管理后台（Site Manager → Appearance → Themes）导入或覆盖对应 CSS 文件。
